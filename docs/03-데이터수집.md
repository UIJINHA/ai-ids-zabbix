# 03. Python 데이터 수집

## 구성
- Zabbix API (JSON-RPC) → Python → MariaDB(aiids.metrics)
- 인증: API 토큰을 Authorization 헤더로 전달
- 자동 실행: cron 5분 주기, 매 실행 시 최근 10분 데이터 조회

## 설계 시 고려한 점

### 계정 비밀번호 대신 API 토큰 사용
강의 예제는 user.login 으로 관리자 계정과 비밀번호를 사용하지만,
설정 파일에 관리자 비밀번호를 저장하지 않기 위해 전용 API 토큰을 발급해 사용했다.
토큰이 노출되더라도 해당 토큰만 폐기하면 되고, 계정 자체는 영향을 받지 않는다.
또한 config.py 는 .gitignore 에 등록하고 config.example.py 만 공개했다.

### 중복 저장 방지
cron 주기(5분)보다 조회 범위(10분)를 넓게 잡아, 한 번 실패해도
다음 실행에서 누락분이 채워지도록 했다.
이 경우 동일 데이터가 반복 조회되므로 metrics 테이블에
(host, item_key, clock) 유니크 키를 걸어 중복 저장을 차단했다.
집계 시 평균값이 왜곡되는 것을 막기 위함이다.

### 수집 대상
특정 아이템 키를 지정하지 않고, value_type 이 숫자형(0, 3)인
모니터링 중인 아이템을 전부 수집했다.
어떤 지표가 이상 탐지에 유효한지는 데이터를 본 뒤 판단하는 것이 맞다고 보고,
Feature 선정은 이후 단계로 미뤘다.

## 결과
- 호스트 2대, 아이템 195개 수집
- 최초 실행 시 최근 60분치 9,782건 저장
- cron 자동 수집 정상 동작 확인
